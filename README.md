# 📚 Java Library Management System

A Java-based Library Management System designed to manage books,
borrowing, returning, and book availability.

## 🚀 Features

- Add new books
- Borrow books
- Return books
- View available books
- Supports up to 100 books
- Menu-driven interface

## 🛠️ Technologies Used

- Java
- Java Scanner
- Arrays
- Loops
- Conditional statements
- Switch statements

## ▶️ How to Run

1. Clone this repository.
2. Open the project in NetBeans, VS Code, or another Java IDE.
3. Compile `LibraryManagementSystem.java`.
4. Run the program.
5. Follow the menu instructions.

## 📋 Main Menu

1. Add Book
2. Borrow Book
3. Return Book
4. View Available Books
5. Exit
